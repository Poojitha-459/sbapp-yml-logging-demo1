Spring Boot YAML Logging Demo

Project Description

This project demonstrates how to configure a Spring Boot application using YAML configuration ("application.yml") and implement logging.

Technologies Used

- Java
- Spring Boot
- YAML
- Maven
- SLF4J / Logback

Features

- Configuring application properties using "application.yml"
- Customizing server port and application name
- Configuring logging levels
- Logging application messages to the console and a file
- Customizing logging patterns
- Managing application configuration in a structured format

Purpose

The main purpose of this project is to understand Spring Boot YAML configuration and logging concepts through practical implementation.

How to Run

1. Clone the repository.
2. Open the project in Eclipse or Spring Tool Suite.
3. Update Maven dependencies.
4. Run the Spring Boot application.
